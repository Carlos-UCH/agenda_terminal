<h2>LINUX</h2>

<h3>Installations</h3>


**Ubuntu:** `sudo apt install python3-pip sqlite3`

**Fedora:** `sudo dnf install python3-pip sqlite`

```
pip install -r requirements.txt
```

<h3>Usage - Terminal</h3>

```
python3 agenda.py
```
<div> 
    <li>
        Q/q -> View event
    </li>
    <li>
        E/e -> Create event
    </li>
</div>
